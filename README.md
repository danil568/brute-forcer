# Brute Forcer

Простой брутфорсер паролей на Python. Перебирает пароли из словаря и ищет совпадение.

## Что умеет

- Читает список паролей из файла (словарь)
- Перебирает каждый пароль по очереди
- Сравнивает с целевым паролем
- Останавливается, как только нашёл (break)

## Как запустить

1. Создай файл `passwords.txt` и добавь туда пароли (каждый на своей строке)
2. Запусти: `python brute.py`

Примечание: `passwords.txt` не включён в репозиторий (вынесен в .gitignore) — словари с паролями не хранят в публичном коде.

## Чему научился

- Чтение данных из файла (open, readlines, strip)
- Циклы, сравнение строк, досрочный выход из цикла (break)
- Разделение кода и данных + .gitignore для защиты чувствительных файлов
